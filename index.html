Bước 1: Tải file HTML này về và đổi tên thành index.html, sau đó kéo thả lên Netlify Drop (app.netlify.com/drop) hoặc GitHub Pages để lấy đường link web cố định.

Bước 2 (Trên iPhone Safari): Mở link web → Bấm nút Chia sẻ (ô vuông có mũi tên lên) → Chọn Thêm vào MH chính (Add to Home Screen).

Bước 3 (Trên Android Chrome): Mở link web → Bấm dấu ba chấm (⋮) góc trên → Chọn Cài đặt ứng dụng / Thêm vào màn hình chính.
